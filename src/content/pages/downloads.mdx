AI is changing drastically how data can be analysed. R-Instat was developed with this in mind, and has been built to work alongside other tools. Joining WayPoint and R-Instat together is what we believe the tools of the future will look like.

Here are the tools you can download and use today.

<Section title="WayPoint">

WayPoint is a tool we have created for analysing your data. It is an interface to the same analysis skills offered below. Unlike Claude's chat interfaces, which only have Python sandboxes, WayPoint is not limited to Python and can also work with R.

<ButtonGroup>
<Button href="https://drive.google.com/file/d/1z-c8qvbRJ1yKZzkVrgHoM7QEMmE-KQ-_/view?usp=sharing">Download WayPoint (Windows installer)</Button>
</ButtonGroup>

The installer is large (about 1.2 GB). Google Drive may say it can't scan the file for viruses; choose Download anyway. Windows may also show a "Windows protected your PC" message, because this is an early prototype release. Choose More info, then Run anyway.

</Section>

<Section title="Skills">

A skill that helps Claude analyse your data with you, step by step: it plans the analysis, runs it, then interprets the results, with you reviewing at each stage. It works in English or French. Download the zip, then follow the steps below to add the skill to Claude or ChatGPT.

**Important:** these versions can only use Python, because Claude's chat interfaces only have access to Python sandboxes, not R sandboxes.

Example text to paste (under 1,500 characters):

```text
When I share data and ask a question, work in three separate phases and stop for my approval after each.
1) PLAN: check data quality (missing values, duplicates, odd values, variable types), restate my question, and propose the analysis steps and methods with reasons. Do not run anything yet.
2) EXECUTE: once I approve, clean the data and run the analysis, showing what you did and which assumptions you checked.
3) INTERPRET: once I approve, explain the results in plain language, covering effect sizes, uncertainty and limitations. Do not overclaim.
Use Python. Reply in the language I write in (English or French).
```
